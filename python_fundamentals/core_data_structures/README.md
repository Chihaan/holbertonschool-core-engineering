# Python - Core data structures

## Description
Manipulation des structures de données de base en Python : listes, tuples, dictionnaires et matrices.

## Fichiers

| Fichier | Description |
|---|---|
| `add_tuple.py` | Additionne deux tuples élément par élément |
| `best_score.py` | Trouve la clé associée à la plus grande valeur d'un dictionnaire |
| `common_elements.py` | Trouve les éléments communs entre deux listes |
| `element_at.py` | Retourne l'élément d'une liste à un index donné |
| `print_list_integer.py` | Affiche tous les entiers d'une liste |
| `print_matrix_integer.py` | Affiche une matrice d'entiers |
| `replace_in_list.py` | Remplace un élément d'une liste à un index donné |
| `update_dictionary.py` | Met à jour ou ajoute une clé/valeur dans un dictionnaire |
| `main.py` | Fichier de test |
