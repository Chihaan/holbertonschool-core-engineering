# Python - Exception handling

## Description
Gestion des exceptions en Python : levée d'exceptions personnalisées et exécution sécurisée de code pouvant échouer.

## Fichiers

| Fichier | Description |
|---|---|
| `raise_exception.py` | Lève une exception |
| `raise_exception_msg.py` | Lève une exception avec un message personnalisé |
| `safe_print_division.py` | Effectue une division en gérant les erreurs |
| `safe_print_integer.py` | Convertit et affiche un entier en gérant les erreurs |
| `safe_print_list.py` | Affiche les n premiers éléments d'une liste en gérant les erreurs |
| `safe_print_list_integers.py` | Affiche les entiers d'une liste en gérant les erreurs |
