# Python - Control flow

## Description
Structures conditionnelles et boucles en Python : conditions, affichage de l'alphabet, combinaisons, conversion en hexadécimal.

## Fichiers

| Fichier | Description |
|---|---|
| `positive_or_negative.py` | Affiche si un nombre est positif, négatif ou nul |
| `last_digit.py` | Affiche le dernier chiffre d'un nombre aléatoire |
| `print_alphabt.py` | Affiche l'alphabet en minuscule |
| `print_comb2.py` | Affiche les nombres de 0 à 99 |
| `print_comb3.py` | Affiche toutes les combinaisons de 2 chiffres différents |
| `print_hexa.py` | Affiche les chiffres en hexadécimal |
