# Python - Functions and modules

## Description
Création de fonctions et de modules en Python : opérations arithmétiques, calculs, gestion de casse, chargement de variables.

## Fichiers

| Fichier | Description |
|---|---|
| `add.py` / `add_0.py` | Fonctions d'addition |
| `calculation.py` | Module regroupant plusieurs opérations arithmétiques |
| `calculator_1.py` | Petite calculatrice utilisant le module `calculation` |
| `islower.py` | Vérifie si une chaîne est en minuscule |
| `uppercase.py` | Convertit une chaîne en majuscule |
| `pow.py` | Calcule une puissance |
| `print_last_digit.py` | Affiche le dernier chiffre d'un nombre |
| `variable_load.py` / `variable_load_5.py` | Exercices de chargement de variables entre modules |
