# Python - File handling

## Description
Manipulation de fichiers en Python : lecture, écriture et ajout de contenu.

## Fichiers

| Fichier | Description |
|---|---|
| `read_file.py` | Lit et affiche le contenu d'un fichier |
| `write_file.py` | Écrit du contenu dans un fichier |
| `append_write.py` | Ajoute du contenu à la fin d'un fichier existant |
