# Holberton School - Core Engineering

Ce repository regroupe les projets Python du tronc commun "Core Engineering" : bases du langage, structures de données, programmation orientée objet et notions avancées.

## Sous-dossiers

| Dossier | Description |
|---|---|
| `python_fundamentals/` | Bases du langage Python : hello world, contrôle de flux, structures de données, fonctions/modules, gestion des exceptions |
| `python_oop/` | Programmation orientée objet : modèle de classes/objets, héritage, classes abstraites |
| `python_advanced/` | Notions avancées de Python (manipulation de fichiers, etc.) |
