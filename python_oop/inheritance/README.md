# Python - Inheritance

## Description
Utilisation de l'héritage en Python avec une hiérarchie `BaseGeometry` → `Rectangle` → `Square`.

## Fichiers

| Fichier | Description |
|---|---|
| `base_geometry.py` | Classe de base `BaseGeometry` |
| `1-rectangle.py` / `2-rectangle.py` | Classe `Rectangle` héritant de `BaseGeometry` |
| `1-square.py` / `2-square.py` | Classe `Square` héritant de `Rectangle` |
| `main.py` | Fichier de test |
