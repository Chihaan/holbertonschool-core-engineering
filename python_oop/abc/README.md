# Python - Abstract Base Classes (ABC)

## Description
Utilisation du module `abc` pour définir des classes abstraites en Python, à travers des exemples d'animaux, de formes géométriques et de listes personnalisées.

## Fichiers

| Fichier | Description |
|---|---|
| `animals.py` | Hiérarchie de classes abstraites `Animal` |
| `dragon.py` | Classe `Dragon` héritant de plusieurs classes abstraites |
| `flyingfish.py` | Classe `FlyingFish` héritant de plusieurs classes abstraites |
| `shapes.py` | Hiérarchie de classes abstraites `Shape` |
| `verboselist.py` | Classe `VerboseList` étendant `list` avec des messages |
| `main.py` | Fichier de test |
