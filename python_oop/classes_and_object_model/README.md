# Python - Classes and object model

## Description
Introduction à la programmation orientée objet en Python à travers l'implémentation progressive d'une classe `Square` et d'une classe `Rectangle`.

## Fichiers

| Fichier | Description |
|---|---|
| `0-square.py` à `6-square.py` | Évolution progressive de la classe `Square` (attributs, propriétés, méthodes) |
| `1-rectangle.py` / `2-rectangle.py` | Implémentation de la classe `Rectangle` |
| `main.py` | Fichier de test |
